# build_crew Flow

This project defines a declarative CrewAI Flow in `src/build_crew/flow.yaml`.

## Install

```bash
crewai install
```

## Run

```bash
crewai run
```

Edit the declarative flow definition at `src/build_crew/flow.yaml` to change the flow. Add reusable crews under `src/build_crew/crews/`, custom Python tools under `src/build_crew/tools/`, and shared knowledge files under `src/build_crew/knowledge/`.
